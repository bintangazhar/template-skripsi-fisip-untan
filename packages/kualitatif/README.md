# skripsi-fisip-untan-kualitatif

Template skripsi **penelitian kualitatif** untuk Fakultas Ilmu Sosial dan Ilmu Politik (FISIP) Universitas Tanjungpura (UNTAN), mengikuti *Panduan Penulisan Skripsi FISIP UNTAN*.

Isi template:

- Sampul luar & sampul dalam
- Lembar persetujuan pembimbing & halaman pengesahan
- Abstrak, ringkasan, pernyataan keaslian, motto & persembahan, kata pengantar
- Daftar isi, daftar tabel, daftar gambar, dan daftar lampiran otomatis
- Bagian inti BAB I–VI dengan kerangka sistematika **kualitatif** (fokus penelitian, definisi konsep, alur pikir, subjek & objek penelitian, instrumen, deskripsi hasil dan analisis, dst.)
- Tabel/gambar bernomor per BAB (Tabel 1.1, Gambar 2.1, dst.)
- Kutipan dan daftar pustaka gaya Chicago *author-date* dengan kota penerbit ("Bandung: Refika Aditama")
- Lampiran bernomor otomatis (contoh: panduan wawancara, panduan observasi)

Untuk penelitian kuantitatif, gunakan [`skripsi-fisip-untan-kuantitatif`](https://typst.app/universe/package/skripsi-fisip-untan-kuantitatif).

## Cara Pakai

```sh
typst init @preview/skripsi-fisip-untan-kualitatif:{{VERSI}}
```

Atau di Typst web app: *Start from template* → cari `skripsi-fisip-untan-kualitatif`. Lalu ubah data di bagian atas `main.typ` (judul, nama, NIM, dosen pembimbing, penguji, dst.).
